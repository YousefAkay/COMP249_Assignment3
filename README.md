# SmartTravel System - COMP249 Assignment 2

## How to Run

Compile:
javac -cp "lib\jfreechart-1.5.6.jar;lib\jcommon-1.0.24.jar" -d out src\**\*.java

Run:
java -cp "out;lib\jfreechart-1.5.6.jar;lib\jcommon-1.0.24.jar" driver.SmartTravelDriver

## Features
- Client management
- Trip management
- Transportation and accommodation handling
- CSV file persistence
- Dashboard and chart generation

## Notes
- Output is generated in the output/ folder
- Requires Java JDK 24
